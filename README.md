# Daniel Cabrera Rincon - Portfolio CV

Personal portfolio website showcasing my professional experience as a SAP ABAP Consultant and Full Stack Developer.

## Features

- Interactive timeline with professional experience
- Bilingual support (Spanish/English) with language toggle
- PDF CV download functionality
- Responsive design for all devices
- Modern dark theme with smooth animations

## Tech Stack

- HTML5, CSS3, JavaScript (Vanilla)
- html2pdf.js for PDF generation
- Google Fonts (Inter, Fira Code)
- Font Awesome icons

## Local Development

Simply open `index.html` in your browser, or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve
```

Then visit `http://localhost:8000`

## Deployment

This site is designed for GitHub Pages. Push to `main` branch and it will automatically deploy.
